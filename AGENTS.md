# Workspace Guidelines

## Mathematical Formatting in Chat Responses
* **Never** use raw LaTeX math delimiters (`$...$` or `$$...$$`) in chat responses to the user.
* **Always** use clean Unicode symbols (`x² + y²`, `e₁² = 1`, `e₂ e₁ = -e₁ e₂`, `v⁻¹ = v / ||v||²`, `ℝ`, `∧`, `⨼`, `●`, `•`, `⟹`) and formatted code blocks / tables for derivations.

## Knowledge Base & Cross-Session Memory
* **Always** search and cross-reference existing artifacts in `docs/knowledge_base/` and historical brain sessions in `~/.gemini/jetski/brain/` when answering domain questions, researching strategic topics, drafting PRDs/memos, or implementing algorithms.
* When new markdown artifacts or briefings are generated, link or register them in `docs/knowledge_base/README.md`.
